### Сайты на Django

**[Blogicum](https://github.com/Rufina007/django-sprint4)**: блог-платформа. Пользователи регистрируются, публикуют посты с картинками, выбирают категорию и место, комментируют чужие посты. Пост можно опубликовать с отложенной датой: он появится на сайте, когда наступит нужное время. Редактировать и удалять посты и комментарии может только их автор. На главной, в категориях и в профиле работает пагинация, есть свои страницы ошибок 403, 404 и 500.
Стек: Python, Django, SQLite, Bootstrap.


### REST API

**[YaMDb](https://github.com/Rufina007/api-yamdb)**: API платформы отзывов на фильмы, книги и музыку. Произведения делятся на категории и жанры, пользователи оставляют отзывы с оценкой от 1 до 10, из оценок считается рейтинг. Регистрация идёт через код подтверждения на почту, после него выдаётся JWT-токен. Есть три роли: пользователь, модератор и администратор. Тестовые данные загружаются из CSV одной командой, произведения можно фильтровать, а второй отзыв от одного автора на одно произведение сервис не принимает.
Стек: Python, Django, Django REST Framework, Simple JWT, SQLite, pytest.

### Развёртывание проектов

**[Kittygram](https://github.com/Rufina007/kittygram_final)**: сервис для публикации фотографий котиков с их достижениями. Основная задача здесь была в развёртывании: готовое приложение (Django и React) упаковано в контейнеры, для разработки и для сервера настроены отдельные compose-файлы, секреты вынесены в `.env`, SQLite заменена на PostgreSQL. GitHub Actions запускает тесты, собирает три образа, публикует их в Docker Hub и разворачивает проект на сервере по SSH. Если тесты не прошли, на сервер ничего не попадает.
Стек: Python, Django, Django REST Framework, PostgreSQL, Docker, Nginx, GitHub Actions.

### Flask

**[YaCut](https://github.com/Rufina007/async-yacut)**: сервис коротких ссылок. Короткий идентификатор создаётся автоматически или вводится вручную, по нему происходит переход на длинную ссылку. Есть API для других сервисов: создать ссылку и получить длинную по короткой, ошибки приходят в JSON. Ещё сервис умеет загружать несколько файлов на Яндекс Диск одновременно и выдаёт короткую ссылку на каждый.
Стек: Python, Flask, Flask-SQLAlchemy, Alembic, aiohttp, API Яндекс Диска.

### Боты и игры

**[Homework Bot](https://github.com/Rufina007/homework-bot)**: Telegram-бот, который раз в 10 минут проверяет статус домашней работы в API Практикума и пишет, когда он меняется: работу взяли на проверку, приняли или вернули с замечаниями. При запуске бот проверяет, что заданы все токены. Все события и ошибки пишутся в лог, об одной и той же ошибке бот сообщает один раз.
Стек: Python, pyTelegramBotAPI, requests, logging.

**[The Snake](https://github.com/Rufina007/the_snake)**: классическая «Змейка». Змейка управляется стрелками, ест яблоки и растёт, а при столкновении с собой игра начинается заново. Код разбит на классы: общий класс игровых объектов, от него наследуются змейка и яблоко.
Стек: Python, Pygame.
